# Contributing

Thank you for your interest in contributing to Enterprise Dealer Service Hub.

This project is an open-source Salesforce application focused on dealer management, order lifecycle automation, pricing approvals, and customer support.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Ensure your code follows Salesforce development best practices.
5. Submit a pull request with a clear description of your changes.

## Development Guidelines

- Follow Apex best practices.
- Use meaningful names for classes, methods, and variables.
- Follow Salesforce governor limits.
- Include Apex tests for new functionality.
- Follow secure coding practices.
- Keep Lightning Web Components reusable and maintainable.

## Reporting Issues

Please use GitHub Issues to report bugs or suggest improvements.

Include steps to reproduce the issue and expected behaviour.

Thank you for helping improve this project.
